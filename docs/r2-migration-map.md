# R2 migration map — Web Player + Author into `musicpack-core`

*Written before any migration work (task §2). The legacy repository
`../musicpack` (GitHub `whepper/musicpack`) is the immutable oracle; every
path below is relative to the repository root unless marked "oracle".*

## Source-of-truth states

The oracle's working tree contains uncommitted work that IS the current
production behavior (the Rust-playback-default feature set, Sept 18):
modified `bootstrap.ts`, `controller.ts`, `player-core/{engine,index,player}.ts`,
`sync-wasm.sh`, four e2e specs and `helpers.ts`; untracked
`app/public/rust-*.js` (5 platform workers), `rust-{engine,playback-engine}.ts`,
ten `rust-*.spec.ts` e2e specs and four `rust-*.test.ts` unit tests.
**The migration copies the oracle's working-tree state** (what actually runs)
and records those files here as "differs from oracle git HEAD".

## Playback code classification (task §5)

1. **Required Web/platform adapters** — `controller.ts` (composition +
   backend policy), `rust-playback-engine.ts` + `rust-engine.ts` +
   `public/rust-*.js` (canonical Rust/WASM path), `audio-worklet.ts`,
   `ring-buffer.ts`, `streaming-resampler.ts`, `media-session.ts`,
   `native-backend.ts` (FLAC/WAV representations), `capability.ts`,
   `loudness.ts`, `transition-profiles.ts`, `waveform.ts`,
   `duration-repair-storage.ts`.
2. **Compatibility shim** — `musepack-engine.ts` + `decoder.worker.js` +
   frozen `musepack.{js,wasm}`: the Emscripten engine remains load-bearing
   for (a) OPFS offline playback (`chooseBackend` routes `local-file`
   sources there), (b) the `?legacyPlayback=1` escape hatch, (c) the
   `rust-differential` oracle specs.
3. **Obsolete** — nothing deleted; `rust-decoder-probe.js` labeled as a
   debug probe.
4. **Test/oracle material** — `tests/node/wasm-gapless.mjs`, `tests/perf/`,
   the `rust-differential`/`rust-soak`/`rust-underrun` e2e specs.
   `player-core/` remains the platform-independent domain core (pure TS
   today; the Rust engine already owns decode/sequencing hot paths; a
   full Rust domain move is later roadmap, oracle-backed).

## WASM pipeline (task §6) — replaces `sync-wasm.sh`

```
cargo build -p musicpack-wasm --release --target wasm32-unknown-unknown
        ↓ wasm-bindgen --target no-modules
web/app/public/rust/          (gitignored, rebuilt when stale)
        ↓ vite build / vite dev
Web application
```

`web/scripts/build-wasm.mjs` rebuilds only when crate sources are newer
than the artifacts; `dev`, `build`, and the e2e runner all go through it.
The frozen legacy decoder is committed (see above), so no emsdk anywhere.

## Intentional deviations (task §18 record)

- **D1** `sync-wasm.sh` → `build-wasm.mjs` (pipeline, not behavior).
- **D2** e2e harness starts the **Rust** server (the cutover) instead of
  the C binary; fixture packages vendored under `web/tests/fixtures/`.
- **D3** hand-written readers/workers promoted from ignored copies to
  committed sources; the Emscripten decoder committed as a frozen,
  provenance-stamped compatibility artifact.
- **D4** migrated from the oracle working tree (list at top); oracle git
  HEAD does not contain the Rust-default playback work.
- **D5** `tests/node/run.mjs` defaults repointed: frozen decoder at
  `web/app/public/musepack.js` (was the oracle's `build-wasm/` output)
  and fixtures at `tests/fixtures/musepack/` (this repo's layout);
  `MUSICPACK_WASM_JS` override unchanged.
- **D6** author-local adaptations: the musicbrainz test fixture
  (`mb-release-live-shape.json`) vendored to
  `author/src-tauri/tests/fixtures/` (was an oracle-root
  `include_str!`), and `scripts/with-cargo.sh` copied into `author/`
  (was an oracle-root sibling script); `package.json` path updated.
  No behavior change.
- **D7** the three byte-injection specs (`rust-audio`, `rust-playback`,
  `rust-worker`) read the binding from the generated
  `web/app/public/rust/` (they pointed at the sibling oracle checkout's
  `target/wasm-browser`, which now serves only as a fallback) — they
  were silently skipped before this repoint; they now run everywhere the
  pipeline has produced the artifact.
- **D8** (intentional, a11y): the album artwork dialog now **moves focus
  into itself on open**, so Escape closes it. In the oracle the dialog's
  Escape branch was dead code — focus stayed on the invoking button and
  never reached the dialog. Found by the new `a11y.spec.ts`; the
  behavioural change is limited to keyboard dismissal of the viewer.
- No other observable product behavior changes.
