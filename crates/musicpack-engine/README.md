# musicpack-engine

Deterministic, platform-neutral **PCM engine adapter** between
[`musicpack-core`](../..) and a host's audio output.

It implements the core's `player::Engine` seam over `AudioDecoder` using
only the standard library and safe Rust (`#![forbid(unsafe_code)]`), and
compiles natively and for `wasm32-unknown-unknown`.

```text
PlaybackItem → SourceBackend → Box<dyn Read> → audio::open() → AudioDecoder
                                                                     │
                DecodeSession { decoder · bounded ring · streaming resampler }
                                                                     │
                              DecoderEngine (implements player::Engine)
                                  │                       │
                             consume()      prepare_next / advance / begin_crossfade
                                  │                       │
                             host output     host completion → Player::on_crossfade_complete
```

## What it contains

- **Ring buffer** (`ring.rs`) — fixed-capacity, interleaved, absolute
  read/write playheads, drop-on-overflow, and a *reported* playhead base
  used to rebase across a crossfade swap.
- **Streaming resampler** (`resampler.rs`) — the reference browser engine's
  linear interpolation, exact length normalization, mono/stereo mapping and
  tail flush.
- **Equal-power mixer** (`mixer.rs`) — `cos(t·π/2)` / `sin(t·π/2)`, missing
  lane as zero, actual-overlap accounting.
- **Sources** (`source.rs`) — `SourceBackend`; `MemorySourceBackend` and
  `PackageSourceBackend` (over a core `PackageBackend`, e.g. MPAK members).
- **Decoder factory** (`decoder.rs`) — `DecoderFactory`; the default
  sniffing factory reuses core `audio::open`. This is where codecs are
  registered (WAV, FLAC, and the native Musepack SV8 decoder).
- **Decode session** (`session.rs`) — decoder + ring + resampler with
  demand-driven bounded pumping, watermarks and EOF/underrun separation.
- **Engine** (`engine.rs`) — `DecoderEngine`, the `player::Engine`
  implementation, plus the host output seam `consume(frames, dst)`.

## What it deliberately is not

No device/audio API, no browser API, no HTTP, no OPFS, no filesystem, no
timers, no threads, no async runtime, no DSP crate. A host owns all of those
and drives this crate by pumping and consuming frames. The player core stays
sample-blind. See `docs/architecture.md` §3/§4.

## Differential status

The ring, resampler and mixer are **byte-exact ports** of the reference
TypeScript (`web/app/src/lib/playback/*.ts`). The mixer is gated by
`tests/xfade_oracle.rs`, which replays `tests/data/xfade_oracle.jsonl`
(generated by `tools/xfade_oracle.ts` through the real
`MusicPackPcmProcessor`) with no tolerance.

## Testing

```sh
cargo test -p musicpack-engine
cargo check -p musicpack-engine --target wasm32-unknown-unknown
cargo clippy -p musicpack-engine --all-targets -- -D warnings
```

`tests/integration.rs` drives real WAV/FLAC fixtures through
`AudioDecoder → DecoderEngine → Player`; `tests/mpak_integration.rs` covers
an MPAK member.
