# Whole-encoder oracle (Phase 15G)

Committed `.mpc` streams produced by the reference `mpcenc` binary from
deterministic integer-only 16-bit stereo WAVs, plus the manifest the Rust
whole-encoder test replays. The Rust test never invokes C.

## Provenance

* reference `mpcenc` `build/codec/mpcenc/mpcenc` (revision `05d97a5`,
  `musicpack` HEAD `d687b645760c68cca2d1cb36ab586db0092ff0b3`);
* Apple clang 21, arm64, `-O0`, `-ffp-contract=off`, `FAST_MATH` +
  `CVD_FASTLOG`, `MPC_ENABLE_ENC_SIMD_KERNEL`;
* scalar-forced via `--impl scalar --psy-impl scalar` (the strict
  compatibility target; verified byte-identical to the committed fixtures
  for all 21 cases in Phase 15G.2, so no regeneration was needed);
* generated by `tools/gen_encoder_fixtures.py <mpcenc> <reference-repo>`.

The PCM generator is integer-only (LCG noise, ramp, alternating, constant,
impulse, transient) so the Python and Rust generators are bit-identical
without floating point.

## Compatibility result

`tests/encoder_whole.rs` reproduces the exact reference bytes for **21 of 21**
cases (140420 bytes).

Phase 15G.1 resolved the two remaining divergences (`q5-44100-oneframe`,
`q5-44100-multiblock`, both in decoder-delay/padded frames). Root cause: the
frozen CVD tables `PULS`/`COS_WIN` (`src/psy/cvd_tables.rs`) were byte-swapped
by the table generator (`struct.pack("<f", v).hex()` misread as a hex
integer), so `CosWin[0] = 1.0` became a denormal ~4.6e-41, the cepstral window
collapsed, and voice was never detected. Scalar-forced C output was verified
byte-identical to the committed SIMD fixtures on both cases, proving the
divergence was a genuine table bug rather than scalar-vs-SIMD drift. See the
Phase 15G.1 report and the `frozen_cvd_tables_match_reference_constants` /
`harmonic_spectrum_detects_voice_like_reference` regression tests in
`src/psy/cvd.rs`.

## Diagnostics

`tools/extract_encoder_trace.c` replays the exact `mpcenc.c` frame loop
(including decoder-delay frames) with scalar kernels forced and dumps a
per-frame trace (`Res`, `SCF`, `MS`, `Q`, `X`, `SMR`, FFT power/phase,
unpredictability, transient flags, CVD voice lines, psy state). It is temporary
migration tooling: not built by Cargo, never invoked by Rust tests.

The Rust side exposes the same boundaries through
`MusepackEncoder::encode_traced` (`FrameTrace`).
