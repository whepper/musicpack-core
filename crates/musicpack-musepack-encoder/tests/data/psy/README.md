# Psychoacoustic oracle (Phase 15F)

Frozen reference data for the scalar psychoacoustic model. Generated by
`tools/extract_psy_oracle.c`, which links the reference `libmpcpsy.a` and calls
the production `Init_Psychoakustik`, `SetQualityParams`,
`Init_Psychoakustiktabellen`, `Psychoakustisches_Modell`, `RaiseSMR`,
`MS_LR_Entscheidung`, `TransientenCalc`, `PowSpec*`, `PolarSpec1024`, `rdft`
and `Init_FastMath` with the scalar spectrum kernels forced. The C reference is
never modified, and no Rust test invokes it.

## Reference provenance

* reference revision `05d97a5` (`musicpack` HEAD
  `d687b645760c68cca2d1cb36ab586db0092ff0b3`);
* Apple clang 21, arm64, `-O0`, `-ffp-contract=off`;
* `FAST_MATH` + `CVD_FASTLOG`;
* scalar psychoacoustic kernels (`mpc_psy_set_impl(MPC_PSY_SCALAR)`).

Build (from `crates/musicpack-musepack-encoder/tools`):

```sh
cc -O0 -ffp-contract=off -std=gnu11 -DFAST_MATH -DCVD_FASTLOG \
   -I <reference>/codec/include -I <reference>/codec/libmpcpsy \
   extract_psy_oracle.c \
   <reference>/build/codec/libmpcpsy/libmpcpsy.a -lm -o /tmp/extract_psy_oracle
/tmp/extract_psy_oracle tables|fft|math|model|ms .
```

## Files

| Path | Contents |
|---|---|
| `manifest.txt` | one line per model case: `name config qual rate frames max_band ms_mode cvd ns_order min_smr bytes` |
| `<config>_<case>.f32le` | model outputs, `2374` little-endian `f32` per frame |
| `ms_<config>_k<n>.txt` | `MS_LR_Entscheidung` sub-oracle (hex bit patterns) |
| `math.txt` | `FAST_MATH` primitives (hex bit patterns / integer values) |
| `rdft2048.txt`, `cepstrum2048.txt` | FFT primitives |
| `powspec{256,1024,2048}_k<n>.txt`, `polar1024_k<n>.txt` | windowed spectra |
| `kernels.txt`, `psy_<config>.txt` | frozen numerical tables (hex bit patterns) |

### Model record layout (per frame, all `f32le`)

```text
SMR_L(32) SMR_R(32) SMR_M(32) SMR_S(32)
SMRr_L(32) SMRr_R(32) SMRr_M(32) SMRr_S(32)   # after RaiseSMR
TransientL(19) TransientR(19) Transient(32)
ANSspec_L(512) ANSspec_R(512) ANSspec_M(512) ANSspec_S(512)
```

Total `2374` values per frame. Only bands `0..=Max_Band` are reference-defined
for `SMR*`; bands above `Max_Band` are left untouched by the reference and are
**not** compared. `MS_Flag` beyond `Max_Band` is likewise undefined and not
compared.

### Configurations

`q4-44100`, `q5-44100`, `q6-44100`, `q7-44100`, `q5-48000`, `q5-37800`,
`q5-32000`. PCM cases: silence, impulse, constant, alternating, sine,
multitone, lowfreq, highfreq, noise, transient, stereo_same, stereo_diff,
left_only, right_only, phase_invert, ramp — three consecutive frames each.

PCM generation is deterministic: a continuous stream windowed exactly like
`mpcenc` (`[g[f·1152]]·448 ++ g[f·1152 .. f·1152+1152]`, `M/S = (L±R)/2`), and
the noise cases use the exact LCG `s = s·1664525 + 1013904223`.

## Numerical discoveries

* `pow(10.0, x)` must be the generic `pow`; LLVM can lower a literal base ten
  to `exp10`, which is not bit-identical to the reference.
* The frozen FFT windows/twiddles must be generated by `Init_FFT`
  (`Init_Psychoakustik`) before dumping — otherwise they are all zero. The
  reference `rdft` requires `cft1st`'s first-half twiddle `w[2*k1]` (not a
  value carried across loop iterations).
* The pre-echo/post-mask state seeds from the **degenerate** `SampleFreq == 0`
  table generation, i.e. `(float)pow(10, -2.3)`.
* `CVD_UNPRED * 0.01 * vocal` is `f64` arithmetic narrowed once.
* `POW10(0.1 * minSMR)` computes `0.1 * minSMR` in `f64`.
* `logfast` squares in `f32` first (`d = (x*x) as f64`) then squares twice in
  `f64`.
* `MS_Flag` and `SMR` beyond `Max_Band` are undefined in the reference.
